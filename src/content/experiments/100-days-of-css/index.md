## Why I built it

To sharpen my CSS through pure CSS art, animation, 3D transforms and SVG.

## What I learned

1. Each day lives in its own folder with its styles, markup, an optional script and a README of notes.
2. Days 51 to 100 in SCSS: mixins, functions, @for loops and @if directives.
3. Each challenge wrapped in its own class, so styles never bleed across days.
4. A Webpack setup that loads every entry.
