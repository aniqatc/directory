## Why I built it

To sharpen my CSS through pure CSS art, animation, 3D transforms and SVG. I got through 82 of the 100 days, most of them between October and December 2023, and wrote a README for each one with the key concepts and what tripped me up.

## What I learned

1. One folder per day, with its styles, markup, an optional script and its notes, each wrapped in its own class (`.day-001`) so styles never bleed across days. A Webpack setup loads every entry.
2. Stacking: `z-index` only works on positioned elements, and pseudo-elements stack above their parent. To put one behind, I gave it its own stacking context and a negative `z-index` ([day 1](https://github.com/aniqatc/css-100/tree/main/entries/001)).
3. Restarting an animation: removing and re-adding a class doesn't replay it, so I forced a reflow in between ([day 2](https://github.com/aniqatc/css-100/tree/main/entries/002)).
4. Timing inside `@keyframes`: percentages start each circle's scale at a different point in one cycle, with no `animation-delay` ([day 4](https://github.com/aniqatc/css-100/tree/main/entries/004)).
5. Transforms overwrite each other: a `scale()` in an animation cancels the `translate(-50%, -50%)` used to centre. On [day 26](https://github.com/aniqatc/css-100/tree/main/entries/026) I centred with negative margins instead, and left [day 16](https://github.com/aniqatc/css-100/tree/main/entries/016)'s workaround as it was, as a reminder of why.
6. SVG elements can't have pseudo-elements, so the tooltips on [day 5](https://github.com/aniqatc/css-100/tree/main/entries/005)'s graph moved into one absolutely positioned div.
7. Gradients don't animate: a `conic-gradient` spinner wouldn't run, so I used an SVG stroke instead. `outline-offset` gave me a dotted border I could push in or out ([day 10](https://github.com/aniqatc/css-100/tree/main/entries/010)).
8. Drawing SVG lines with `stroke-dasharray` and `stroke-dashoffset`, made simpler with the `pathLength` attribute (days [22](https://github.com/aniqatc/css-100/tree/main/entries/022), [30](https://github.com/aniqatc/css-100/tree/main/entries/030) and [68](https://github.com/aniqatc/css-100/tree/main/entries/068)).
9. Drawing with strokes: a stroke so thick it fills the circle, so `stroke-dasharray` and `stroke-dashoffset` open and close Pac-Man's mouth ([day 21](https://github.com/aniqatc/css-100/tree/main/entries/021)). Text turned into outlines in Figma could then be drawn in too ([day 34](https://github.com/aniqatc/css-100/tree/main/entries/034)).
10. Placing SVG: a `<polygon>` can't be positioned on its own, so I wrapped one in three `<svg>` tags, rotated them and trimmed the corners with `overflow: hidden` for a Penrose triangle ([day 17](https://github.com/aniqatc/css-100/tree/main/entries/017)). Leaving out `viewBox` let CSS do the scaling ([day 24](https://github.com/aniqatc/css-100/tree/main/entries/024)), and in a `<path>`, uppercase commands are absolute and lowercase ones relative ([day 28](https://github.com/aniqatc/css-100/tree/main/entries/028)).
11. Invisible space: a giant quote mark carried extra space above and below it until `line-height: 0` made `top: 0` mean the top ([day 12](https://github.com/aniqatc/css-100/tree/main/entries/012)).
12. Out of sight isn't out of the way: hidden elements still caught clicks until I set `pointer-events: none` (days [13](https://github.com/aniqatc/css-100/tree/main/entries/013), [24](https://github.com/aniqatc/css-100/tree/main/entries/024) and [39](https://github.com/aniqatc/css-100/tree/main/entries/039)).
13. State without JavaScript: hidden radio and checkbox inputs, styled labels and the `~` selector for tabs, toggles and buttons, including two labels for one checkbox (days [19](https://github.com/aniqatc/css-100/tree/main/entries/019), [20](https://github.com/aniqatc/css-100/tree/main/entries/020), [27](https://github.com/aniqatc/css-100/tree/main/entries/027), [36](https://github.com/aniqatc/css-100/tree/main/entries/036), [71](https://github.com/aniqatc/css-100/tree/main/entries/071) and [74](https://github.com/aniqatc/css-100/tree/main/entries/074)).
14. One animation for many elements: an `--index` set from JavaScript, then `calc()` for each element's duration and delay. Variables inside `@keyframes` turned four animations into two, and negative delays start an element partway through (days [31](https://github.com/aniqatc/css-100/tree/main/entries/031), [39](https://github.com/aniqatc/css-100/tree/main/entries/039), [63](https://github.com/aniqatc/css-100/tree/main/entries/063) and [68](https://github.com/aniqatc/css-100/tree/main/entries/068)).
15. Different transitions in and out: one sequence for opening and another for closing, plus removing the grey tap highlight on mobile ([day 25](https://github.com/aniqatc/css-100/tree/main/entries/025)).
16. Flexbox beyond one row: an auto margin instead of a nested container ([day 9](https://github.com/aniqatc/css-100/tree/main/entries/009)), and `flex-basis: 100%` to break a table onto its own row ([day 62](https://github.com/aniqatc/css-100/tree/main/entries/062)).
17. Forms: a custom file upload, number and range inputs styled across browsers, and `:valid` flipping a form over when the password matches (days [15](https://github.com/aniqatc/css-100/tree/main/entries/015), [32](https://github.com/aniqatc/css-100/tree/main/entries/032), [53](https://github.com/aniqatc/css-100/tree/main/entries/053) and [76](https://github.com/aniqatc/css-100/tree/main/entries/076)).
18. SCSS from day 51: `@for` loops that write a separate `@keyframes` for each element, mixins with parameters, `@function`, `@if` / `@else`, and the modulo operator for alternating transitions (days [51](https://github.com/aniqatc/css-100/tree/main/entries/051) to [59](https://github.com/aniqatc/css-100/tree/main/entries/059)).
19. 3D in practice: `perspective` sets how deep the space is, so a bigger value pushes things further away ([day 14](https://github.com/aniqatc/css-100/tree/main/entries/014)). `preserve-3d` keeps children in their parent's 3D space, and `translateZ()` pushes faces out along the depth axis to build a cube and a carousel (days [37](https://github.com/aniqatc/css-100/tree/main/entries/037) and [48](https://github.com/aniqatc/css-100/tree/main/entries/048)). `perspective()` gives one element its own space ([day 25](https://github.com/aniqatc/css-100/tree/main/entries/025)), and `backface-visibility` hides the back of a flip card (days [14](https://github.com/aniqatc/css-100/tree/main/entries/014) and [76](https://github.com/aniqatc/css-100/tree/main/entries/076)).
20. Learning 3D by taking it apart: on [day 18](https://github.com/aniqatc/css-100/tree/main/entries/018) I couldn't see how the flip worked, so I rebuilt it from the creator's code and removed properties until I understood how it was happening. Days [57](https://github.com/aniqatc/css-100/tree/main/entries/057) and [58](https://github.com/aniqatc/css-100/tree/main/entries/058) had harder formulas, which I reverse-engineered to understand.
