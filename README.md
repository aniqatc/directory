# aniqa.dev

A holding page for aniqa.dev while the new site is finished: the "Aniqa." hero, the Portfolio / Lab switch, "Coming very soon", my email and GitHub.

It's one static page in `public/` with no build step (`vercel.json` tells Vercel to serve the folder as is). Every path shows the page, and `/lab` opens it in Lab.

- The new site (Astro) is on the [`astro-rebuild`](https://github.com/aniqatc/directory/tree/astro-rebuild) branch and replaces this when it's merged.
- The old React portfolio is tagged [`react-v1`](https://github.com/aniqatc/directory/tree/react-v1).
